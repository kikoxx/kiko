### dev-session.sh
- Navigate to the directory below
```bash
# Local binaries store here
~/.local/bin/dev-session.sh
```
- After pasting the code, do the following
```
chmod +x ~/.local/bin/dev-session.sh
echo 'alias lab="~/.local/bin/dev-session.sh"' >> ~/.zshrc
source ~/.zshrc
```
